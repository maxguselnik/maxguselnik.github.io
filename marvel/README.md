# Marvel · Гид по киновселенной

Неофициальный русскоязычный гид по просмотру MCU с постерами 38 фильмов и 7 сериалов.

- Хронологический порядок и порядок кинопремьер.
- Поиск, фильтр непросмотренного и личный прогресс в браузере.
- Адаптивные карточки, анимации появления и плавное обновление интерфейса.
- Поддержка системной настройки уменьшения движения.

Сайт: https://maxguselnik.github.io/marvel/

## Локальный запуск

В папке проекта выполните `python -m http.server 8080` и откройте http://localhost:8080.

Сайт не требует установки зависимостей или сборки. GitHub Pages публикует каталог `marvel` из корня ветки `main` репозитория `maxguselnik/maxguselnik.github.io`.

Отметки просмотренного хранятся в `localStorage` этого браузера и адреса сайта. После переноса с другого домена прогресс начинается отдельно.
